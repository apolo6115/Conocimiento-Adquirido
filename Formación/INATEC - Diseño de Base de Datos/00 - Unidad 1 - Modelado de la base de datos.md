# Unidad 1 - Modelado de la base de datos

## ¿Qué es?
Índice y mapa de navegación de la Unidad 1 del manual **Diseño de Base de Datos** (INATEC, Especialidad: Técnico Especialista en Programación). La unidad abarca integralmente el modelado conceptual y lógico de datos: ciclo de diseño, modelo entidad-relación, cardinalidad, normalización, reglas de integridad y definición de llaves.

Fuente: Manual del Estudiante "Diseño de Base de Datos", Instituto Nacional Tecnológico (INATEC), Primera Edición, Mayo 2021.

## Etapas del modelado de datos
El modelado de datos determina la estructura lógica de una base de datos y el modo de almacenar, organizar y manipular los datos en cuatro etapas sucesivas:
1. **Descripción de requisitos**: Especificación en lenguaje natural.
2. **Diseño conceptual**: Modelo Entidad/Relación ([[Modelo Entidad-Relación]], [[Elaborar un diagrama Entidad-Relación]]).
3. **Diseño lógico**: Modelo relacional en tablas ([[Diseño lógico de la base de datos]], [[Normalización de tablas]]).
4. **Diseño físico**: Implementación física en SQL y restricciones de tabla ([[Restricciones de la base de datos]]).
